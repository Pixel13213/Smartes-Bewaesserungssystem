		Smartes Bewässerungssystem (SBS)

Bei dem SBS handelt es sich um ein System, welches die Bodenfeuchtigkeit misst und basierend darauf entweder per Pumpe die Pflanze bewässert. Dies hilft dabei, dass weniger Pflanzen an fehlenden Wasser sterben. Alle Dateien bis auf die .ino sind relevant für die Website. Die .ino ist was auf den Mikrocontroller geladen werden muss, damit dieser die Webserver startet und die Sensoren ansteuert.

Hinweise:
-Vor Nutzung muss die IP-Adresse angepasst werden, damit eine Verbindung hergestellt werden kann
-Zur automatischen Bewässerung muss zu erst unter Einstellung eine Schwelle eingetragen werden
Achtung:
Auf 13 Zoll Bildschirm angepasst, es könnte zu Verschiebung kommen
